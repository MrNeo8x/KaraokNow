# MVP Requirement Traceability Matrix

Updated: 2026-11-22. Requirements below are copied from the master plan. API and automated-test references describe current repository evidence. `UAT-FR-*` entries are proposed pilot checks, not executed UAT results. `TC-*` references point to scenarios in the master plan's QA strategy and are planned unless separately evidenced by an automated test.

| FR | API / current implementation | Automated evidence | UAT trace | Status and gap |
|---|---|---|---|---|
| FR-001 Create branch | `POST /v1/merchant/branches`; read/update/status routes exist | `be/test/venue.e2e-spec.ts` — “supports audited branch and room CRUD/status using soft deletion”; “rejects invalid credentials, tenant context and timezones” checks invalid timezone and duplicate branch code | UAT-FR-001: Owner creates a branch with valid timezone and sees it in branch list | Implemented baseline; automated happy path and validation covered |
| FR-002 Create room | `POST /v1/merchant/rooms`; branch room list, read/update/status routes exist | “supports audited branch and room CRUD/status using soft deletion” creates and updates a room | UAT-FR-002: Owner creates a room in a branch and checks its details | Implemented baseline; duplicate room-code behavior is not directly asserted by current E2E |
| FR-003 Pricing rules | Quote and tenant-scoped plan/rule/special-date APIs; hold details stores a server-calculated price snapshot | Unit tests cover priority/tie and arithmetic; PostgreSQL E2E covers matching, hold price mismatch, immutable snapshot and replay | UAT-FR-003: Compare a quote against PO-approved examples; booking snapshot copy remains planned | Catalog and hold snapshot implemented; booking confirmation persistence and UAT remain |

## Execution status

The automated references above are present in the repository; planned `TC-*` cases are not represented as passed tests. The proposed `UAT-FR-*` checks have not been run with merchants. This matrix is a traceability artifact, not a claim that all 15 requirements are implemented or accepted.
